### Handwritten Devanagari recognition

A **convolutional neural network** for handwritten Devanagari character recognition, paired with an Android draw-and-predict application.

- **Focus:** image classification and a usable prediction interface.
- **Tools:** TensorFlow, Python, CNNs, Android.
- **Reported result:** 99.98% test accuracy in the project's evaluation context; see the repository for the implementation.

### Perceparator — audio source separation

A **transformer-based dual-speaker audio separation model**, trained on **LibriMix**. The work explores sequence modelling for isolating speakers from a mixed audio recording.

**PyTorch · Transformers · Python · LibriMix**

[Explore Perceparator](https://github.com/VoidCU/perceparator)
